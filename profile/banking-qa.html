Banking QA Test Management Framework

A reproducible, synthetic banking QA project showcasing strategy, traceability, defect management, SQL validation and release governance.

Project overview

This independent learning project simulates internal transfers between bank accounts. It includes risk assessment, documented test coverage, Jira-style defect records, a SQLite database with synthetic data, automated SQL integrity checks, a release decision and a dashboard.

Management evidence

Test strategy, risk register, traceability matrix, test-case catalog, defect workflow and release-readiness rules.

Technical evidence

SQLite schema and sample transactions, Python standard-library validation, generated CSV reports and a browser-based dashboard.

Where to find the code: The separate Banking-QA-Test-Management-Framework.zip contains the complete project. After publishing it to a GitHub repository, add the repository URL here.
